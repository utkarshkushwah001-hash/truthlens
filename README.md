# TruthLens 🔍

TruthLens is a web-based project focused on detecting whether an image is authentic or AI-generated by analyzing image properties and running different detection checks.

This project is currently being built as an experimental AI authenticity detection tool and is under active development.

## Current Features

* Image Upload System
* Image Preview Before Analysis
* Backend Image Processing using Flask
* Upload Pipeline between Frontend and Backend
* Temporary Image Storage on Server
* Heuristic Detection based on image file properties
* Analysis Animation Interface
* Dynamic Result Flow

## Tech Stack

**Frontend**

* HTML
* Tailwind CSS
* JavaScript

**Backend**

* Python
* Flask
* Flask-CORS

## Project Workflow

Upload Image
→ Send image to backend
→ Save image on server
→ Run image property checks
→ Analyze image
→ Generate result
